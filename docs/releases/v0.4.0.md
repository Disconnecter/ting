# Ting 0.4.0

## Changes

- **Check command.** `Ting.app/Contents/MacOS/Ting --check <file.yaml>` checks
  micro-app files without a running Ting. It opens no window, reads no
  config and writes no file. It prints one `file:line: message` line per
  problem, the same text as the micro-app error log, or `<file>: ok`. Exit code
  0 means every file is good, 1 means a problem was found, 2 means a wrong call.
- **Format document for any coding agent.** The micro-app format document,
  `FORMAT.md`, is rewritten for any coding agent (Claude Code, Codex, pi and
  others), holds the full text of its examples, and now ships inside
  `Ting.app` as well as on GitHub.
- **Copy Agent Prompt.** A new item in the menu-bar menu and a button in
  Settings → Advanced → Micro-apps copy a ready text for your agent: where to
  read the format, how to check the file, and where to put it. Add your own
  task at the end and paste it into the agent. `Ting --agent-prompt` prints the
  same text.

## Upgrade and install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

To upgrade an installed copy, choose **Check for Updates…** in the menu-bar
menu. Your settings, leader and bindings are kept.

For a new or manual installation, download `Ting-0.4.0-universal.zip` from
[Releases](https://github.com/bobuk-io/ting/releases/latest) and unzip it. Quit
any running copy of Ting, move `Ting.app` to `/Applications` (replace the old
copy for a manual upgrade), and open it. Ting lives in the menu bar and has no
Dock icon. On first launch, choose a leader key; there is no default leader.

The official release is signed with Developer ID, notarized by Apple, and
includes a stapled notarization ticket. Verify the archive with
`SHA256SUMS.txt` if desired. Ting needs no Accessibility or Input Monitoring
permission.
