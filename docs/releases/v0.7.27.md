# Ting 0.7.27

- **Extended key capture:** a new **Settings › Keys & Launch › Extended key capture (HID)** switch, off by default (`"extendedKeys": true` in `config.json`). Ting then reads the keys that macOS ignores — Stop, Again, Undo, Cut, Copy, Paste, Find, Execute, Menu, Select and F21–F24 — straight from the keyboard, so they can be the leader, any other Ting hotkey and keys inside the menu, with or without modifiers. It needs Input Monitoring, which Ting asks for once when you turn it on; Ting looks only for these keys and keeps nothing it reads (BobukKit 0.13.1).
- **Any key in the menu:** bindings are no longer limited to letters, digits, Space, Return and F-keys. Signs such as `[`, `;` and `/`, Tab, Home, End, Page Up and Down, keypad Clear and keys without a name (`key10` for the ISO § key) work too. Esc, ⌫ and the arrows still move through the menu.

Settings, bindings, micro-apps, and history are compatible with 0.7.26.
