# Ting 0.7.2

## Fix

- Selecta no longer consumes ordinary keys during AppKit's key-equivalent
  handling. Arrow keys and Return now reach the menu navigation added in 0.7.1.
  Command shortcuts such as Command-Q remain blocked while the menu is open.

## Upgrade

Choose **Check for Updates…** in Ting. Settings, bindings, micro-apps and
permissions are preserved. Requires macOS 14 or later; the signed, notarized
and stapled universal app supports Apple Silicon and Intel.
