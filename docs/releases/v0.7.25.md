# Ting 0.7.25

- **Fix: window hotkeys no longer crash Ting.** Pressing a window-command hotkey while a Ting window was in front, for example right after recording it in Settings › Windows, quit Ting. Ting's own windows are now moved on the main thread; other apps' windows are still moved in the background, so an unresponsive app cannot freeze Ting.

Settings, bindings, micro-apps, and history are compatible with 0.7.24.
