# Ting 0.7.23

- **Chatta Claude and ACP agent authentication (BobukKit 0.11.3):** ACP agent subprocesses now inherit `USER`, `LOGNAME` (falling back to the current macOS account name when unset), `SHELL`, and standard proxy/TLS environment variables (`HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY`, `SSL_CERT_FILE`, `NODE_EXTRA_CA_CERTS`). This fixes Claude Code failing with *"OAuth session expired and could not be refreshed"* when looking up its macOS Keychain credentials under `$USER`.

Settings, bindings, micro-apps, and history are compatible with 0.7.22.
