# Ting 0.7.0

## Changes

- **A calculator in launcha.** Type digits and an operator, such as `2*(3+4)`,
  `1,5 × 4`, `200 + 15%`, `2^10` or `sqrt(2)`: the value comes first, above any
  app or file, and `Return` copies it. Both `.` and `,` are decimal points.
  `+ - * / ^`, `× ÷`, parentheses, `mod`, percent, `pi`, `e` and the functions
  `sqrt`, `abs`, `round`, `floor`, `ceil`, `ln`, `log`, `exp`, `sin`, `cos`, `tan`
  (radians) work; results keep up to 12 digits after the point. Ting computes
  it itself, with decimal numbers, so `0.1 + 0.2` is `0.3`. It is on by default:
  turn it off with **Calculate in launcha** in Settings › General, or with
  `"calculator": false` under `launcha` in the config file.
- **Updates are checked at bobuk.io.** Sparkle now reads the update feed at
  `https://bobuk.io/apps/ting/appcast.xml`, so a new release shows up as soon as
  it is published. The archives still come from GitHub Releases and are accepted
  only with Ting's EdDSA signature, as before.

## Privacy

Each update check now goes to the bobuk.io server instead of GitHub, so that
server sees ordinary request data, including your IP address. The download of a
new release still goes to GitHub. Turn automatic checks off in Settings ›
General if you prefer to check yourself.

## Upgrade and install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

To upgrade an installed copy, choose **Check for Updates…** in the menu-bar
menu. Your settings, leader, bindings, micro-apps and permissions are kept.
Ting 0.6.1 and older find this release through the GitHub feed; from 0.7.0 on,
Ting checks bobuk.io.

For a new or manual installation, download `Ting-0.7.0-universal.zip` from
[Releases](https://github.com/bobuk-io/ting/releases/latest) and unzip it. Quit
any running copy of Ting, move `Ting.app` to `/Applications` (replace the old
copy for a manual upgrade), and open it. Ting lives in the menu bar and has no
Dock icon. On first launch, choose a leader key; there is no default leader.

The official release is signed with Developer ID, notarized by Apple, and
includes a stapled notarization ticket. Verify the archive with
`SHA256SUMS.txt` if desired. Ting asks for Automation and Accessibility only
when a micro-app needs them and never for Input Monitoring.
