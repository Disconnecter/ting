# Ting 0.7.16

## Save lowkey pages as PDF from a micro-app

The native `lowkey` step now supports `action: save-pdf` with a required, templated `file:` path. This calls the bundled `lowkeyctl` directly, without a shell or synthetic input.

```yaml
format: ting.microapp/2
description: Save a demo page as PDF.
input: none
timeout: 60
steps:
  - lowkey: demo
    action: save-pdf
    file: ~/Desktop/demo-page.pdf
    timeout: 60
```

- Requires lowkey 0.1.2 or later in `/Applications` and an already-open saved-site window on its saved origin.
- Prints the entire current document to A4 PDF using WebKit's print styles, not just the visible viewport. Lazy content and virtualized lists are not automatically loaded or expanded.
- `~` expands to the current user's home directory. Paths with spaces are passed as one argument. Existing files are never overwritten.
- Input passes through unchanged on success. Failures stop the run without retry. Console runs require `--allow-effects`.

The checker rejects a missing or empty `file:` and fields that do not apply to this action.
