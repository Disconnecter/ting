# Ting 0.7.20

- **Much faster panel opening and lower CPU usage:** the main focus of this release is eliminating CPU spikes when opening and using Ting's panels.
- **Bounded, cached app indexing in launcha:** `launcha` now scans only application folders up to two levels deep (`/Applications/*.app` and direct subfolders such as `/Applications/Utilities/*.app`), skips regular files and common package bundles without touching LaunchServices, caches unchanged `.app` metadata, and skips full rescans on open when watched app directories have not changed. Reopening `launcha` drops from hundreds of milliseconds of CPU to under 1 ms.
- **Smoother selecta, launcha, and Clipbawd rendering:** removed redundant recomputation cascades and disk reads on `launcha` open, moved card drop shadows onto static background layers instead of offscreen-blurring composite panels on every keystroke or hover, stopped `selecta`'s blinking slot animation when hidden (and switched it to GPU layer opacity), precompiled and cached Clipbawd Markdown highlighting and file icons, and adopted BobukKit 0.5.2 (avoiding redundant `PickerSurfaceView` redraws, caching Carbon keyboard layouts, and reusing prepared fuzzy queries).

Settings, bindings, micro-apps, and history are compatible with 0.7.19.
