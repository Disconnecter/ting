# Ting 0.7.15

- If you switch between keyboards, record another shortcut in **Settings › General › Second leader**. Both leader keys open the same selecta bindings, and either works with double tap for launcha. Your existing leader and bindings carry over.
- Both leader keys are reserved when assigning global shortcuts. Settings and hotkey registration now use the same rules to resolve conflicts.
- launcha keeps each search result attached to its original target as it ranks matches, including the exact app bundle when multiple copies share a bundle identifier.
