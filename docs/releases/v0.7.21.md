# Ting 0.7.21

- **Chatta — built-in ACP agent chat and Ting configuration workspace:** open Chatta from Ting's menu bar, **launcha** (`chatta`), a **selecta** binding, or an optional global hotkey in **Settings › Chatta**. Switch between **Chat** (text-only conversation) and **Configure Ting** (a sandboxed workspace on your Ting folder that reads `CONFIGURING.md` / `FORMAT.md`, edits bindings, and writes and validates micro-apps with `ting-micro`). Closing the window hides it and keeps the conversation ready while automatically stopping idle agent subprocesses after a configurable timeout.
- **ACP agent auto-detection and one-click adapter install (BobukKit 0.9.4):** Chatta discovers installed ACP agents (`Antigravity`, `Codex`, `Claude`, `Pi`, `Kimi`, `Gemini`, `OpenCode`) across common macOS tool paths (Homebrew, mise, nvm, fnm, Volta, Bun, pnpm, `~/.npmrc`), detects when a base CLI like `codex`, `claude`, or `pi` is installed without its `-acp` bridge, and offers **Install ACP Adapter** (or **Copy Command**) directly in Chatta and **Settings › Chatta**. Includes a shimmer status sweep while generating and Seatbelt PTY support for workspace validation commands.
- **Headless `chatta:` micro-app step:** call your local ACP agent from any micro-app pipeline with optional `agent`, `model`, `effort`, `system`, `access` (`text`, `read`, `write`), and `cwd`, inheriting defaults from **Settings › Chatta** and streaming output into the result panel.
- **Micro-app search, panel sizing, timeouts, and locale fixes:** `choose` steps now rank title matches above subtitle-only matches; **Settings › Micro-apps** adds configurable maximum timeout (`60–86400 s`, default `300 s`, with per-micro-app `timeout` capped by `maxTimeout`), result panel width (`480–1200 pt`), and result text size (`11–24 pt`); and micro-app subprocesses drop inherited `LANGUAGE` to avoid locale override issues.

Settings, bindings, micro-apps, and history are compatible with 0.7.20.
