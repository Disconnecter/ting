# Ting 0.7.8

## Changed

- The default sound for opening an app, link or file is now **Purr**. This also
  applies to existing configurations that do not specify a sound. Your selected
  sound is preserved.

## Fixed

- `ting-micro` started from a terminal no longer waits five seconds for the
  login shell and then falls back to a short `PATH`. Micro-app commands now run
  in their own session, without the terminal of the process that started them.

## Upgrade

A downloaded copy: choose **Check for Updates…** in Ting. A Homebrew copy:
choose **Update Ting via Homebrew…** in Ting's menu. Settings, bindings,
micro-apps and permissions are preserved. Requires macOS 14 or later; the
signed, notarized and stapled universal app supports Apple Silicon and Intel.
