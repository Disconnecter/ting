# Ting 0.7.22

- **Opt-in agent tools in Chatta Chat mode:** built-in agent tools (such as `web_search`) stay off by default (`chatta.allowTools: false`), running inside the sandbox without host filesystem access when enabled. On the first tool call while off, Chatta asks inline whether to **Allow Always**, allow for **This Session**, or **Don't Allow**, and automatically retries your message once allowed. Toggle tools anytime from the Chatta header or **Settings › Chatta**.
- **Immediate window and input focus:** opening Chatta from the menu bar, launcha, selecta, or a global hotkey now reliably activates the window and places keyboard focus directly in the message field.
- **Upgraded Chatta chat experience (BobukKit 0.11.2):**
  - **Auto-connect on send:** start typing and press `⌘↩` immediately, even after an idle disconnect.
  - **Attachments, tables, activity disclosure, and history:** attach or drag & drop files and images (or paste clipboard images), inspect collapsible tool and thought activity, render Markdown tables, recall previous prompts with `↑`/`↓`, and regenerate or hover-copy replies.
  - **Remembered choices and reliability:** Chatta remembers your last agent, model, and reasoning effort across sessions (when not pinned in Settings), handles stale model IDs cleanly when switching agents, prefers versioned `mise` binaries over stale shims, coalesces streaming chunks, and cleanly terminates agent process groups.

Settings, bindings, micro-apps, and history are compatible with 0.7.21.
