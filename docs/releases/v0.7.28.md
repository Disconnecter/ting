# Ting 0.7.28

- **Homebrew updates and `brew trust`:** Homebrew now loads casks from taps other than its own only after you trust them, so a copy installed from `bobuk-io/tap` failed to update with "Refusing to load cask bobuk-io/tap/ting from untrusted tap". The **Update Ting via Homebrew…** window now recognizes this, explains it and offers **Trust and Update**: only when you click it, Ting runs `brew trust --cask bobuk-io/tap/ting` (this cask only) and the same update again. If your copy cannot update to 0.7.28 for this reason, run `brew trust bobuk-io/tap` once, then `brew upgrade --cask bobuk-io/tap/ting`.
- **Fresh releases are found:** Homebrew updates refresh the taps first, so a release published minutes ago is installed instead of "already up to date".
- **Plain `brew upgrade` includes Ting:** the cask no longer says `auto_updates`, so `brew upgrade` and `brew outdated` list Ting without `--greedy`.

BobukKit 0.13.3. Settings, bindings, micro-apps, and history are compatible with 0.7.27.
