# Ting 0.7.9

- Existing single-site lowkey bindings use the `lowkeyctl` helper when available, so toggling one site does not bring another forward.
- Use the native `lowkey` micro-app step with lowkey 0.1.1 to control saved windows, inspect a page, wait, click, fill, select or attach a file. `status` and `inspect` support JSON output.
- Use `preview` to review text, Markdown, code or console output in the panel before the next step. Continue preserves the input; Esc cancels. Console runs reject interactive previews and require `--allow-effects` for lowkey actions.
