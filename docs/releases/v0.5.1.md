# Ting 0.5.1

## Changes

- **Faster menu opening and app switching.** Ting preloads app icons and caches
  app paths when it loads your bindings, including nested groups. Already
  running apps are activated directly, without going through LaunchServices
  or resolving file-system paths for every running process. Activation of a
  running app starts before the leader menu hides.
- **Less work to show the menu.** Ting reuses the menu view rather than
  rebuilding it on each opening. The window fits the menu and uses the system
  shadow instead of a SwiftUI-rendered shadow.
- **Aligned keycaps.** Small keycaps now have the same minimum width, whether
  or not they show a second keyboard-layout letter. Rows for Space and other
  keys without that letter no longer shift to the left.

## Upgrade and install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

To upgrade an installed copy, choose **Check for Updates…** in the menu-bar
menu. Your settings, leader, bindings and micro-apps are kept.

For a new or manual installation, download `Ting-0.5.1-universal.zip` from
[Releases](https://github.com/bobuk-io/ting/releases/latest) and unzip it. Quit
any running copy of Ting, move `Ting.app` to `/Applications` (replace the old
copy for a manual upgrade), and open it. Ting lives in the menu bar and has no
Dock icon. On first launch, choose a leader key; there is no default leader.

The official release is signed with Developer ID, notarized by Apple, and
includes a stapled notarization ticket. Verify the archive with
`SHA256SUMS.txt` if desired. Ting needs no Accessibility or Input Monitoring
permission. A micro-app with a `notify` step asks for permission to show
notifications at its first notification.
