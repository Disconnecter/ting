# Ting 0.7.4

## Fix

- A copy of Ting installed with Homebrew no longer runs Sparkle. It does not
  check for updates on its own and never shows the Sparkle update window.
- In such a copy, Ting's menu (the menu-bar icon and the gear of selecta and
  launcha) and the Updates section of Settings offer **Update Ting via
  Homebrew…** instead of **Check for Updates…**. It runs exactly
  `brew upgrade --cask --greedy bobuk-io/tap/ting` with the `brew` of the
  Homebrew prefix that installed Ting. It never upgrades anything else.
- A window shows the command, the live output of brew and the real result:
  updated, already up to date, cancelled, or the error with brew's output and
  exit code (for example no network, a Homebrew lock or a password prompt that
  cannot be answered). After an update, Ting starts again from its installed
  place and shows the same result. A copy that you downloaded yourself still
  updates with Sparkle, as before.

## Cause

Before this release, Ting started Sparkle in every release copy that had an
update feed and key. It never checked who installed the app, so a copy that
Homebrew manages offered Sparkle updates too. Ting now counts a copy as
Homebrew-managed only when a Caskroom record `<prefix>/Caskroom/ting/<version>/Ting.app`
of the cask `ting` resolves to the running Ting.app. Ting looks in `/opt/homebrew`,
`/usr/local`, `HOMEBREW_PREFIX` and the prefix of a `brew` found in `PATH`. In an
unclear case Ting keeps Sparkle.

The exact error of the Sparkle install in a Homebrew copy was not reproduced
for this release, so its cause is not known. This release no longer runs
Sparkle in such a copy, so that failure cannot occur there.

## Upgrade

A downloaded copy: choose **Check for Updates…** in Ting. A Homebrew copy of
0.7.3 or older still has the Sparkle update; quit Ting, run
`brew upgrade --cask --greedy bobuk-io/tap/ting` in a terminal, and open it
again. Later updates then work from Ting's menu. Settings, bindings,
micro-apps and permissions are preserved. Requires macOS 14 or later; the
signed, notarized and stapled universal app supports Apple Silicon and Intel.
