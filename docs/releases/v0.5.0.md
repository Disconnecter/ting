# Ting 0.5.0

## Changes

- **Micro-apps with steps.** A micro-app can now be a list of steps instead of
  one shell command: shell or Python code, HTTP requests, AI calls (OpenAI,
  Anthropic or any OpenAI-compatible server such as Ollama), text templates,
  JSON fields, opening a URL and notifications. The output of each step is the
  input of the next one, like a shell pipe. Steps read params, the outputs of
  earlier steps, your login-shell environment and keychain items. AI answers
  and long outputs stream into the panel while they come. The format stays
  `ting.microapp/2`; existing files work as before.
- **Libraries.** Steps that several micro-apps share live once in
  `~/.config/ting/micro/libs/`. A micro-app runs a library with `call`, or
  inherits it and changes only some values, for example one translate
  micro-app per language. A changed library asks again for approval of every
  micro-app that uses it.
- **`ting-micro` console tool.** `Ting.app/Contents/MacOS/ting-micro` checks
  and runs micro-apps from the terminal: `check`, `run` (input from stdin,
  result on stdout) and `check-config` for `config.json`.
- **Set up Ting with a coding agent.** A new guide, `CONFIGURING.md`, ships
  inside `Ting.app` and tells Claude Code, Codex or pi how to add micro-apps,
  key bindings and settings and how to check them. **Copy Agent Prompt** now
  points to it. Ask in plain words, for example "Leader t a should translate
  the clipboard into German".
- **New examples.** Wikipedia summary, web search, translate, translate to
  Ukrainian and Ask Claude. The Python examples need the Xcode Command Line
  Tools.

## Upgrade and install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

To upgrade an installed copy, choose **Check for Updates…** in the menu-bar
menu. Your settings, leader, bindings and micro-apps are kept.

For a new or manual installation, download `Ting-0.5.0-universal.zip` from
[Releases](https://github.com/bobuk-io/ting/releases/latest) and unzip it. Quit
any running copy of Ting, move `Ting.app` to `/Applications` (replace the old
copy for a manual upgrade), and open it. Ting lives in the menu bar and has no
Dock icon. On first launch, choose a leader key; there is no default leader.

The official release is signed with Developer ID, notarized by Apple, and
includes a stapled notarization ticket. Verify the archive with
`SHA256SUMS.txt` if desired. Ting needs no Accessibility or Input Monitoring
permission. A micro-app with a `notify` step asks for permission to show
notifications at its first notification.
