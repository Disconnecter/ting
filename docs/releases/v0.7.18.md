# Ting 0.7.18

- Fuzzy search in launcha: letters may be scattered and longer queries may contain a typo, so `1pwd` and even `1pvd` find 1Password. One typo is allowed from four letters, two from eight; a three-letter query gets one typo only when nothing else matches (`1pv`). The first letter must match. Names that contain the query as typed always come first, so an often used app never jumps above a close match only because you typed loosely. Wrong keyboard layout search keeps working.
- Matched letters are highlighted in launcha results.
- Within each match group, apps you launch more often rank higher, also for loose matches; equal matches prefer the shorter name, so `sfr` lists Safari above 1Password for Safari.
- New opt-in setting **Rank by apps you use** (Settings › Keys & Launch): launcha also counts the apps you switch to outside launcha, at most once per app every 30 minutes, and can list running apps higher or lower. The record stays on this Mac in `app-usage.json`; turning the setting off deletes it.
- Micro-app choice fields, micro-app choice lists and the bindings filter in Settings use the same fuzzy matching. The bindings list keeps its tree order.
- Clipbawd now previews a single copied PNG or JPEG file (such as screenshots captured to a file) while still pasting it as a file; unreadable or removed files fall back to the file icon.
- Pressing `⌘,` in selecta, launcha or Clipbawd now closes the launcher and opens Settings, including on Russian and Ukrainian keyboard layouts; other `⌘` shortcuts such as `⌘Q` remain swallowed.
- Settings is now a regular Ting window with its close control in the window strip, a fixed sidebar, readable page titles and grouped controls. The settings search uses the shared search field.
- Launcha, leader and clipboard panels, hotkeys, keyboard layout handling and Homebrew updates now come from the shared BobukKit library used by every bobuk.io app.

Settings, bindings and history are compatible with 0.7.17.
