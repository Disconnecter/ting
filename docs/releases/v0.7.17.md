# Ting 0.7.17

Unreleased.

- Replaced the crowded Settings tabs with a resizable sidebar and search across individual settings. Leader and launcha controls are in Keys & Launch; micro-app diagnostics and permissions have their own page. Rare clipboard retention/privacy controls are collapsed until needed.
- Shortened the menu: config, reload and Copy Agent Prompt are under Tools; About and update commands are under Ting. Errors are grouped under Needs Attention.
- Added opt-in clipboard history between launches, off by default. Defaults are 100 entries, 50 MiB and 30 days; all limits are adjustable and 0 days disables age expiry. Expired copies are removed hourly; copying content again renews its age, but reusing it does not. Existing explicit item limits are preserved.
- Stored history is local, private to your user and excluded from backups, without additional encryption. Clear History and disabling Clipbawd delete both memory and disk history; disabling persistence deletes the archive but keeps the current session. Settings show usage, archive size and storage errors.
- Added basic Markdown syntax coloring without embedded-image loading, and thumbnail/duration previews for one MP4/MOV/M4V video per clipboard copy, up to 30 seconds and 32 MiB. Movies are retained as bytes and can be copied after the original file is removed. Other files remain path references. PNG, JPEG and TIFF image support is preserved.

Settings and bindings remain compatible. The history archive lives in `~/Library/Application Support/Ting/Clipbawd/`; uninstalling with data removal also removes this directory. Deleting local history is not a secure erase of filesystem snapshots or existing backups. Approved micro-app history templates reject video entries explicitly, as they already do for images.
