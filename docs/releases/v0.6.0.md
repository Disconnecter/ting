# Ting 0.6.0

## Changes

- **Micro-apps know what you were working on.** A micro-app lists in
  `context:` what Ting reads when it starts, and Ting reads only that: the
  active app (`app`: name, bundle id, path), the files selected in Finder and
  the folder of its front window (`finder`), the URL and title of the front
  browser tab (`browser`: Safari, Chrome, Arc, Brave, Edge, Vivaldi, Chromium),
  the selected text (`selection`) and the title and document of the front
  window (`window`). Steps read them as `${context.finder.selection}`, code as
  `$TING_CONTEXT_FINDER_SELECTION`.
- **Micro-apps can type into the app.** A `keys` step presses keys in the app
  that was in front (`keys: [cmd+a, return]`), a `paste` step pastes text there,
  and `output.to: [app]` pastes the result, for example in place of the
  selected text. Ting puts the clipboard back after it pastes.
- **The approval panel shows more.** It names what a micro-app reads and
  whether it sends key presses or text to the app.
- **`ting-micro run --context`.** The console tool takes context values such as
  `--context app.name=Safari`. It never sends keys or text; `keys` and `paste`
  steps print a note instead.
- **New examples.** About the active app, Checksum of Finder files, Copy page
  link, Sort selected lines and Search in a new tab.

## Permissions

Ting asks for a permission only when an approved micro-app needs it:

- **Automation** for Finder or a browser, for the `finder` and `browser`
  context. macOS asks once per app.
- **Accessibility** for the `selection` and `window` context, `keys` and
  `paste` steps and the `app` output. Turn on Ting in System Settings ›
  Privacy & Security › Accessibility. When an app does not give its selected
  text through Accessibility, Ting presses `⌘C` there and puts the clipboard
  back.

Micro-apps without these features need no permission, as before. Ting still
never asks for Input Monitoring and does not observe keystrokes outside its own
menu. Approve key-sending micro-apps as carefully as code: with Accessibility
granted, they can do in the app in front what you can do with the keyboard.

## Upgrade and install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

To upgrade an installed copy, choose **Check for Updates…** in the menu-bar
menu. Your settings, leader, bindings and micro-apps are kept; existing
micro-app files work as before.

For a new or manual installation, download `Ting-0.6.0-universal.zip` from
[Releases](https://github.com/bobuk-io/ting/releases/latest) and unzip it. Quit
any running copy of Ting, move `Ting.app` to `/Applications` (replace the old
copy for a manual upgrade), and open it. Ting lives in the menu bar and has no
Dock icon. On first launch, choose a leader key; there is no default leader.

The official release is signed with Developer ID, notarized by Apple, and
includes a stapled notarization ticket. Verify the archive with
`SHA256SUMS.txt` if desired. A micro-app with a `notify` step asks for
permission to show notifications at its first notification.
